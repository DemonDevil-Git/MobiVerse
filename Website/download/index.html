安装说明

  1. 下载并打开 DMG。
  2. 把 MobiVerse 拖入“应用程序”文件夹。
  3. 首次打开后，将 MOBI、AZW3、CBZ、CBR、ZIP、PDF 或 EPUB 拖入窗口。

安全与隐私

MobiVerse 在本机分析和转换图书，不会把你的电子书上传到服务器。项目以 GPLv3 开源，安装包与源码均由官方 GitHub 仓库发布。

MobiVerse 不移除 DRM。受保护或无法读取的文件会被清楚标记。

Windows 版本

Windows 11 ARM64 构建与测试说明会随对应 Release 发布。请通过官方发布记录确认适合你的版本，不要从第三方下载站获取安装包。
