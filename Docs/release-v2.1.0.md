# MobiVerse v2.1.0

MobiVerse 2.1 introduces a native high-speed conversion path for PDF comics and image-heavy PDF books.

## PDF Performance

- PDF input now bypasses Calibre's general-purpose document reflow.
- PDFKit renders pages directly into an Apple Books-friendly fixed-layout EPUB.
- The EPUB is built once instead of being generated by Calibre and rebuilt a second time.
- JPEG pages are written at a 2200-pixel maximum edge with quality tuned for illustrated reading.
- Pages are processed sequentially and released promptly to reduce peak memory use.
- Already-compressed images use ZIP store mode instead of wasting CPU on repeated compression.
- Conversion progress displays the current and total PDF page count.

In real-world testing, a roughly 400MB PDF comic completed in under 10 seconds. Actual performance depends on page count, image encoding, storage speed, and Mac hardware.

## Conversion and Reading

- Opens EPUB files directly in the built-in preview.
- Converts DRM-free MOBI, AZW, AZW3, CBZ, CBR, ZIP, and PDF files into EPUB.
- Rebuilds image-heavy books as stable fixed-layout EPUB3 output for Apple Books.
- Bundles Calibre for formats that still require it; PDF fast conversion does not depend on Calibre.
- Keeps conversion local on your Mac.

## PDF Output Notes

PDF pages are preserved visually as fixed-layout images. Selectable PDF text, links, annotations, and forms are not retained in the EPUB output.

## Install

1. Download `MobiVerse-2.1.0.dmg` from this release.
2. Open the DMG.
3. Drag `MobiVerse.app` into `Applications` and replace the previous version.
4. Launch MobiVerse and open or drop a supported book.

## Known Limitations

- MobiVerse does not remove DRM.
- This DMG is not Apple Developer ID notarized. macOS Gatekeeper may require users to approve opening it manually.
- EPUBCheck validation is skipped unless an EPUBCheck runtime is available.
